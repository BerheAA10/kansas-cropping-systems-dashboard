# Kansas Cropping Systems Decision Dashboard V3.0

## Dashboard scope

Interactive Streamlit dashboard for comparing agronomically relevant continuous crops and crop rotations in Kansas under rainfed, irrigated, and potential-production conditions for 1981–2018.

## Version 3.0

- Official dashboard name: **Kansas Cropping Systems Decision Dashboard V3.0**.
- Continuous wheat (`WT`) is excluded from dashboard selection, comparison, mapping, and producer-optimizer rankings.
- Wheat remains fully available as a crop within the four-crop `SB-MZ-SG-WT` rotation.
- The source and processed datasets are not deleted or rewritten; the V3 exclusion is applied at the dashboard boundary so V1 and V2 remain reproducible.
- The existing GitHub repository and Streamlit deployment URL remain unchanged.

## Included base systems

- Continuous maize (`MZ`)
- Continuous sorghum (`SG`)
- Continuous soybean (`SB`)
- Soybean–maize (`SB-MZ`)
- Soybean–maize–sorghum (`SB-MZ-SG`)
- Soybean–maize–sorghum–wheat (`SB-MZ-SG-WT`)
