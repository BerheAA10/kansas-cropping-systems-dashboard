# Kansas Cropping Systems Decision Dashboard V2.0

## Dashboard scope

Interactive Streamlit dashboard for comparing continuous crops and crop rotations in Kansas under rainfed, irrigated, and potential-production conditions for 1981–2018.

## Version 2.0

- Official dashboard name: **Kansas Cropping Systems Decision Dashboard V2.0**.
- The Streamlit browser-tab title and visible page heading use the V2.0 name.
- The existing GitHub repository and Streamlit deployment URL remain unchanged.
- Agronomic, economic, water-use, spatial, and optimizer calculations are unchanged by this title update.
